# WinForms Profile Card Demo

A small **C# WinForms** learning project that demonstrates common desktop UI controls through a profile-card workflow. Users can fill in basic details, select a city and hobbies, choose an image, preview the submitted information, and open a print preview.

> This repository is intentionally kept as a documented learning project. It is not presented as a production-ready profile-management system.

## Features

| Area | Included behavior |
| --- | --- |
| Form controls | Text fields, radio buttons, checkboxes, combo box, and multi-select list |
| Image workflow | File selection and local preview for the profile picture |
| Data preview | Renders entered profile details in a summary view |
| Print workflow | Opens a print-preview flow for the completed card |

## Requirements

- Windows
- Visual Studio 2022 or newer with the **.NET desktop development** workload
- .NET Framework 4.7.2 developer pack

## Run locally

1. Clone the repository.
2. Open `ControlExample/ControlExample.sln` in Visual Studio.
3. Restore any required framework references if Visual Studio asks.
4. Press `F5` to build and run the application.

## Project structure

```text
ControlExample/
├── ControlExample.sln
└── ControlExample/
    ├── Form1.cs                 # Form behavior and event handlers
    ├── Form1.Designer.cs        # WinForms layout generated by Visual Studio
    ├── Form1.resx               # Form resources
    └── Program.cs               # Application entry point
```

## Next improvements

Future work could replace direct file copies with a controlled application-data directory, validate all inputs before submission, add a persistence layer, and separate UI behavior into smaller classes.

## Notes on repository hygiene

Build artifacts such as `bin/` and `obj/` are intentionally ignored. The repository contains only the source and configuration needed to reproduce the build locally.
